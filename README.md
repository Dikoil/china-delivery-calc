# 📦 Доставка из Китая — Калькулятор сравнения

Адаптивный веб-калькулятор (для ПК и смартфона) с поддержкой установки как приложения (PWA) и работы без интернета. Помогает быстро сравнить итоговую стоимость заказа из Китая через пункт выдачи **Jana Post** и через **бесплатную официальную доставку** (с учётом НДС и комиссий).

## Возможности
- Точный расчёт по 24 городам Казахстана (базовый тариф и скидка от 10 кг).
- Автоматическая загрузка актуального курса **USD/KZT** с возможностью ручного ввода в блоке **«Настройки»**.
- Настройка процента НДС/комиссий (по умолчанию `21%`) и собственного тарифа `$/кг`.
- Расчёт точки безубыточности по весу («при каком весе Jana Post выгоднее»).
- Установка на телефон (Android / iOS) и ПК как PWA-приложение, работа в офлайн-режиме.

## Как опубликовать на GitHub Pages за 1 минуту (без установки Git)

1. Откройте [github.com](https://github.com) и войдите в свой аккаунт (или создайте бесплатный аккаунт).
2. Нажмите **New repository** (кнопка `+` в правом верхнем углу → *New repository*).
3. Укажите название репозитория, например `china-delivery-calc`, выберите **Public** и нажмите **Create repository**.
4. На открывшейся странице нажмите ссылку **uploading an existing file**.
5. Перетащите в окно браузера **все файлы** из папки `china-delivery-calc`:
   - `index.html`
   - `style.css`
   - `app.js`
   - `manifest.json`
   - `sw.js`
   - `icon.svg`
   - `README.md`
6. Нажмите зелёную кнопку **Commit changes**.
7. Перейдите во вкладку **Settings** репозитория → слева выберите **Pages**.
8. В разделе **Build and deployment** → **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
9. Через 30–60 секунд вверху страницы появится ваша постоянная ссылка вида:
   `https://<ваш-логин>.github.io/china-delivery-calc/`

> 💡 **Как установить на телефон:** откройте полученную ссылку в Chrome (Android) или Safari (iPhone) и выберите **«Добавить на главный экран» / «Установить приложение»**.
